Follow CLAUDE.md and `portfolio-clean-code` section Practice.

1. Run `npm run lint && npm run typecheck && npm test && npm run build`. Stop on failure.
2. Small ordered conventional commits. Each message: why, what, how verified.
3. Push branch; open PR with spec link, change-log summary, test evidence, free-tier impact.
4. Never commit `.env*` or build output.
